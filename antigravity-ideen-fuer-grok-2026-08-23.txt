[KANN-1] Deduplizierung der Perfect-/Potenzialberechnung in collector.py
-----------------------------------------------------------------------
In collector.py ist die Ermittlung der vollständigen Tage und Perfect-Potenziale zwischen `rebuild_month` (Z. 729–761) und `rebuild_year` (Z. 806–838) über ~30 Zeilen identisch dupliziert.

Vorschlag: Eine gemeinsame Hilfsfunktion extrahieren:
```python
def _aggregate_perfect_potentials(days: list[dict]) -> tuple[list[dict], list[dict], float | None, float | None, float | None, float | None]:
    complete_days = [
        row for row in days
        if int(row.get("intervals_due") or 0) == int(row.get("intervals_expected") or -1)
        and int(row.get("intervals_missing") or 0) == 0
        and int(row.get("price_intervals_missing") or 0) == 0
    ]
    paired_m3 = [row for row in complete_days if row.get("cost_dynamic_perfect") is not None and row.get("cost_dynamic_modul3") is not None]
    paired_flat = [row for row in complete_days if row.get("cost_dynamic_flat_perfect") is not None and row.get("cost_dynamic") is not None]
    perfect = _round_or_none(sum(float(row["cost_dynamic_perfect"]) for row in paired_m3) if paired_m3 else None)
    perfect_flat = _round_or_none(sum(float(row["cost_dynamic_flat_perfect"]) for row in paired_flat) if paired_flat else None)
    potential = _round_or_none(sum(float(row["cost_dynamic_modul3"]) for row in paired_m3) - float(perfect) if perfect is not None else None)
    potential_dynamic = _round_or_none(sum(float(row["cost_dynamic"]) for row in paired_flat) - float(perfect_flat) if perfect_flat is not None else None)
    return complete_days, paired_m3, paired_flat, perfect, perfect_flat, potential, potential_dynamic
```
- Nutzen: DRY-Prinzip, garantiert konsistente Aggregation für Monat und Jahr, reduziert Codezeilen.
- Risiko: 0. Pi-3-Kosten: 0.
